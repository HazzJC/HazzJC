# Hi, I'm Harry

I work on a digital therapeutic in the NHS, which is a Class I medical device. I use this GitHub in my free time to learn more about development workflows, prototyping, user feedback and process improvement.

My website, [harryjameschapman.com](https://harryjameschapman.com), is a mid-2000s desktop packed with easter eggs and old features recreated properly. Have a look at Paint.

What I've been making:

- [Ritual](https://ritual.harryjameschapman.com) turns the counselling technique of writing a letter you never send into a candlelit desk. The scene and sound change as you write, and when you're done the page burns. It's privacy focused.
- [Let's Play Games](https://what-should-we-play-chi.vercel.app) shows what your friends own and when everyone's free, and helps you find new games to play together.
- [Channel 30](https://channel-30.pages.dev) is a 30-second comedy knockout where you pick your funniest tiny video and the room crowns a champion. It's my current project.
- [Esports Idle](https://hazzjc.github.io/esportsidle/) is an idle game about running an esports org.
- [LinkMe](https://linkme-5d3.pages.dev/) is a quiz for up to 16 friends. You get four clues and have to find what links them.
- [Accessible Palettes](https://hazzjc.github.io/AccessiblePalettesWCAGColourPaletteGenerator/) makes colour palettes that pass WCAG contrast.
- I ported Anthropic's [Claude Desktop Buddy](https://github.com/HazzJC/claude-desktop-buddy-waveshare-1-85c) to a Waveshare ESP32-S3 with a round screen.
- I reverse-engineered the keyboard lighting on the ZenBook Pro 16X for a [G-Helper fork](https://github.com/HazzJC/g-helper-ZenBookPro16X-UX7602).
- There's also a [duck race](https://hazzjc.github.io/DuckRaceDecider/) with League of Legends chat, for deciding things.
